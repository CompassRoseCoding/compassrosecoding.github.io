For part 3 of this tutorial, we will cover how to allow users to adjust the hue and saturation in their color, or how much white and how much black is in it. To do this, we will also use gradients, one gradient of red to white and one gradient of transparent black to opaque black. JS Canvas allows us to layer these gradients on top of each other, producing a coherent image.

The image to the left is of the first gradient, red to white across the horizontal. The code for this image is as follows; note that the stops for the gradient are slightly off from the edges, in order to allow for areas of pure color that the user can select.

const wth = canvas.width;

const hgt = canvas.height;


//create horizontal gradient from (10, 0) to (100, 0)

const grad1=ctx.createLinearGradient(0, 0, wth, 0)


//fade colors from red to white

grad1.addColorStop(.02, color);

grad1.addColorStop(.98, '#ffffff');

Then we code the vertical transparent-to-black image, with code that's very similar to the first image. The one modification is that instead of a single smooth gradient to the bottom, I added a color stop for a very dark color near the bottom. It's quite hard to differentiate between shades of black, so I simply created more space for lighter shades.

//gradient for brightness

const grad2 = ctx.createLinearGradient(0, 10, 0, hgt - 5);

grad2.addColorStop(.02, 'rgb(0,0,0,0)');

grad2.addColorStop(.95, 'rgb(35,35,35,1)');

grad2.addColorStop(.98, 'rgb(0,0,0,1)');





Then we layer them, which is fairly simple in Canvas. You simply draw them one on top of the other. Note that this will not work unless all canvases above the bottom 'layer' have transparent sections.


Creating a Color Picker in JS Canvas: Part 2

2024-09-18

Hannah Robertson

In our last tutorial, we use the JS Canvas gradient function to create a nice color gradient which displays almost any color you could want. However, it's not interactive, so we can't actually pick a color from it yet. So, part 2!

JS Canvas does support the JS OnClick event, which allows the user to call a function when a mouse clicks on it. In addition, the Canvas even also provides the X and Y coordinates of the mouse when the event fired. This allows us to isolate the pixel on the canvas that has been clicked on.

To do this, we use the context.getImageData(x, y, rectWidth, rectHeight).data. The getImageData function finds the data for a rectangle specified by its parameters: the x and y coordinate of the top left corner, and the width and height of the rectangle in pixels. You can then use the data to create an RGB string that you can return and use as a color (the colString variable, below).

let x = event.clientX;

let y = event.clientY;


let data = ctx.getImageData(5, 5, 1, 1).data;

let colString = 'rgb(' + data[0] + ', ' + data[1] + ', ' + data[2] + ', ' + data[3] + ')';

RGB in JS Canvas is formatted as rgb(red, green, blue, opacity). For example, opaque red would be rgb(255, 0, 0, 1). This string then works to color other parts of the canvas. You can also use the rgb data and transform it into a hex color code to color other DOM elements- this is a great way to create a very intuitive color output.

In addition to coloring an external element as an output for your canvas, it might help to have an element on the canvas to show where is currently selected. The default Firefox picker has a small crosshairs-type selector, but I wanted something more visible, with thicker lines. I also wanted to have a selector with white elements so it shows up well on dark colors.

What I decided on was a circle with a white ring and a black ring to show up easily on all colors. After that, it's just a matter of using the ctx.arc function to draw a 360 degree / 2 * pi arc around the xy coordinates of your pixel. I decided to do a white circle inside and a black circle outside.

context.arc(x, y, radius, 0, 2*Math.PI);

However, depending on how you format your page, you may have an issue. When initializing a JS canvas, often you set the width and height in the HTML code, like the example below. Be aware that if you do that, the canvas will appear to be that size in all layouts. If you decide to use flexible sizing, you might run into difficulties where the pixel of the canvas that is selected isn't the one where your mouse is.

<canvas class="gradient_canvas" id="gradient_canvas" height="500" width="1500"

onload="fillGradientCanvas()"></canvas>

This is because no matter the external size of the canvas in the html, the JS Canvas will always register that it has the amount of pixels specified in this html line. However, the JS OnClick event will register that the canvas has a different width and height in pixels, the current actual size of the canvas. So, often, JS will draw your circle around a point on a direct diagonal between your actual mouse location and the top left corner of the screen (which is 0, 0 in JS Canvas coordinates). Essentially, you need to convert between the two different sizes.

The formula for conversion is pretty simple: first, get the canvas XY coordinates. Canvas XY coordinates are calculated by taking the difference of the event XY coordinates and the coordinates of the top and left of the Canvas object. Then take actual XY coordinates * internal size / actual size, and you have your Canvas coordinate conversion.

let wth = canvas.getBoundingClientRect().width

let hgt = canvas.getBoundingClientRect().height


let left = parseInt(canvas.getBoundingClientRect().left);

let top = parseInt(canvas.getBoundingClientRect().top);


var canvasX = (parseInt(event.clientX) - left) * (canvas.width / wth);

var canvasY = (parseInt(event.clientY) - top) * (canvas.height / hgt);

Using this conversion, you can flexibly size your canvas without issue. You may want to initialize your canvas with the circle someplace visible on it, so your users can figure out how it's supposed to work. In the end, you may wind up with something like this.

Creating a Color Picker in JS Canvas: Part 1

2024-09-09

Hannah Robertson

Sometimes you need a color picker. There's a regular one that comes included in your browser, but it might not be the most user-friendly, due to size or output restrictions. The Firefox default color picker, right, is one of those. While there's a lot of preset colors, customizing your colors is harder- the color gradient picker is a little small, and the saturation gradient picker is quite thin. In addition, this is often rendered very small in the browser, and it does not have a convenient hex code output.

So, how do I make a color picker? Generally you need three items: the color gradient selector (the rainbow rectangle), the color saturation selector (a method of selecting brightness and saturation), and some kind of output. I wanted my output to have both the color shade displayed as a color window, but also to have an RGB output and Hex output as well, for easy copy paste. Firstly, you need to make your color gradient selector.

The ideal is a rainbow, like the Firefox picker has, ideally with a smooth transition between each color. Then, you need a way to indicate which color is currently selected. Firefox uses a little cross with a hollow center- I wanted something a little more obvious, like a circle. This gradient needs to be interactive, of course, so you can select different colors. I decided to use Javascript Canvas because I was already familiar with how it worked.

The first challenge is to create the gradient. You could use an image as a background, but it will give you an error if you try to interact with it using the mouse- there's security concerns there. So, your best bet is to use a rectangle with the built-in canvas gradient function. The JS Canvas gradient function works pretty simply: you call it using the context object (in the example below, the context object is called ctx). The parameters you pass through it are two points in a line, in this case [0, 10] and [0, hgt-5]. The gradient will change colors along this line, with the colors extending infinitely perpendicular to it. For the example below, the line is exactly vertical from the top of the canvas to the bottom. Remember, [0,0] is the top left corner of a JS canvas.

//gradient for saturation

const grad1 = ctx.createLinearGradient(0, 0, wth, 0)

grad1.addColorStop(.02, color);

grad1.addColorStop(.98, '#ffffff');

Then, you add stops. These are the points where you set the color using addColorStop(). The parameters are a little tricky but simple once you understand them: the first is a decimal amount between 0 and 1, designating where the color band should be in the gradient, and the second is the color that should be there. Canvas uses a modified rgb system in this function, where the fourth digit signifies opaqueness, 0 being transparent and 1 being opaque. In the example below, we fade from transparent black to opaque black across the horizontal plane.

const grad1 = ctx.createLinearGradient(0, 0, wth, 0)

grad1.addColorStop(0, 'rgb(0,0,0,0)');

grad1.addColorStop(1, 'rgb(0,0,0,1)');

The full code for a rainbow gradient is below. Essentially, the gist is that there's 6 base colors using RGB, and we want to meld smoothly from one to another.

const grad0 = ctx.createLinearGradient(0, 0, wth, 0);

grad0.addColorStop(.02, 'rgb(255, 0, 0, 1)');

grad0.addColorStop(.18, 'rgb(255, 255, 0, 1)');

grad0.addColorStop(.34, 'rgb(0, 255, 0, 1)');

grad0.addColorStop(.49, 'rgb(0, 255, 255, 1)');

grad0.addColorStop(.66, 'rgb(0, 0, 255 , 1)');

grad0.addColorStop(.81, 'rgb(255, 0, 255 , 1)');

grad0.addColorStop(.98, 'rgb(255, 0, 0, 1)');
